== 2. Normal operation: readers post 8 comments per second (for 4 minutes)
PromQL> up
  job=spamfilter 1
  job=blog 1
PromQL> sum(rate(blog_comments_posted_total[1m]))
   7.798
PromQL> sum by (result) (rate(spamfilter_comments_total[1m]))
  result=ham 5.493
  result=spam 2.309
PromQL> histogram_quantile(0.95, sum by (le) (rate(spamfilter_inference_seconds_bucket[1m])))
   0.005
# alerts (Prometheus):
  none

== 3. The spam filter stops
$ docker compose stop spamfilter
 Container blog-monitoring-spamfilter-1 Stopping 
 Container blog-monitoring-spamfilter-1 Stopped 
# SpamFilterDown fires 35 s after the stop
# CommentsWaiting fires 39 s after the stop
PromQL> up{job="spamfilter"}
  job=spamfilter 0
PromQL> blog_comments_waiting
  job=blog 292
# alerts (Prometheus):
  FIRING SpamFilterDown: The spam filter does not answer; new comments are not published.
  FIRING CommentsWaiting: 292 comments wait for the spam check.
# logs (Loki): what does the worker report?
LogQL> {service="worker"} |= "filter_unavailable"
  {"event": "filter_unavailable", "comment": "474", "error": "ConnectError"}
  {"event": "filter_unavailable", "comment": "474", "error": "ConnectError"}

== 4. The spam filter is back
$ docker compose start spamfilter
 Container blog-monitoring-spamfilter-1 Starting 
 Container blog-monitoring-spamfilter-1 Started 
# all alerts resolved 20 s after the start
PromQL> blog_comments_waiting
  job=blog 0
# alerts (Prometheus):
  none
LogQL> {service="spamfilter"} |= "started"
  {"event": "started", "version": "1.0", "model": "Titeiiko/OTIS-Official-Spam-Model@2586e3d"}
