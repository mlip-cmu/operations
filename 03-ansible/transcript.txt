== 4. The web servers forward comments to both spam filter servers, with the API key
$ curl -X POST localhost:8081/check -d '{"text": "Earn $500 a day from home!!! Click here www.easy-money.biz"}'
{"spam":true,"score":1.0,"version":"1.0-spam1"}
$ curl -X POST localhost:8082/check -d '{"text": "Thanks for sharing, very helpful."}'
{"spam":false,"score":0.0,"version":"1.0-spam1"}
# without the API key, a spam filter server rejects the request:
$ docker exec web1 curl -s -X POST spam1:8000/check -d '{"text": "hi"}'
{"detail":"invalid API key"}

== 6. Drift: someone changes the threshold on spam2 by hand
$ docker exec spam2 sed -i s/SPAM_THRESHOLD=0.5/SPAM_THRESHOLD=0.99/ /etc/spamfilter/spamfilter.env
# dry run: show what Ansible would change
$ uv run ansible-playbook site.yml --check --diff --limit spam2
