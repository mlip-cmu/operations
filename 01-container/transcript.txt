
== 1. Build: stage 1 converts the model (needs PyTorch), stage 2 is the service
$ docker build -q --target model -t spamfilter:build-stage .
sha256:6cdf60ddcaa5e512994c14969bd55023b8ec682d772d516b87dd14d8245aa4cf
$ docker build -q --build-arg APP_VERSION=1.0 -t spamfilter:1.0 .
sha256:48f6bc632193b1b3a99126885a43e21199dcf3fae09bf67de7f0b9b0e7f12a08
spamfilter:build-stage   3136 MB
spamfilter:1.0            785 MB
$ docker run --rm spamfilter:build-stage uv run --no-sync python -c 'import torch; print(torch.__version__)'
2.14.1+cpu
$ docker run --rm spamfilter:1.0 python -c 'import torch'
ModuleNotFoundError: No module named 'torch'
